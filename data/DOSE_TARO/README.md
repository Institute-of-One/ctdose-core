# DOSE_TARO test fixture

A subsample of a **dummy patient** CT acquisition used as the package's regression
fixture. Not patient data: `DOSE TARO` is a phantom/test record created for dose
software validation.

| | |
| --- | --- |
| Scanner | GE LightSpeed VCT (`GE MEDICAL SYSTEMS`) |
| Protocol | chest–pelvis, 5 mm |
| Tube voltage | 120 kV |
| Rotation time | 0.8 s |
| Pitch | 0.984 (from GE `Scan Pitch Ratio (0043,1027)` = `'0.984:1'`) |
| Total collimation | 40 mm |
| Tube current | modulated, recorded per slice in `(0018,1151)` |
| `CTDIvol (0018,9345)` | **absent** |
| DLP record | **absent** |

That last pair is the point: this is exactly the case `ctdose-core` exists for — full
acquisition description and a tube-current profile, but no recorded dose index.

## What was changed

Generated by `tools/make_fixture.py` from the full 147-slice series:

- **Subsampled** to 12 slices at a fixed stride across the whole scan. Striding
  preserves the real scan range and the tube-current modulation; a contiguous block of
  a dozen slices would show neither. Slice locations are the original ones, so the
  slice *spacing* of this fixture is the stride, not the acquisition's 5 mm.
- **Scrubbed**: accession number, institution name and address, station name,
  physician and operator names, birth date, additional history, study ID and the
  request-attributes / referenced-study / referenced-image sequences are removed or
  blanked. Patient name and ID are normalised to `DOSE^TARO` / `CTDOSE-FIXTURE`, all
  dates to `20000101`, and Study/Series/SOP Instance UIDs are regenerated.
- **Untouched**: pixel data, and every acquisition and geometry attribute the dose
  calculation reads.

The full series is not redistributed. Its acquisition parameters — including the
complete 147-value tube-current profile — are in
`tests/data/dose_taro_acquisition.json`, which is what the dose-metric regressions use
so they exercise realistic full-scan numbers without the pixel data.

Regenerate with:

```bash
python tools/make_fixture.py --source /path/to/CT-ExposureDose/data
```
